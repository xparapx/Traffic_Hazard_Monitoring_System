# 위험 모니터링 변수 사전 (실시간 지표 · 인사이트용)

> 관점 구분: 이 문서는 **"도로가 얼마나 위험한가"**(운영 트랙)의 변수.
> **"모델이 얼마나 잘하나"**(연구 트랙)는 [BENCH_VARIABLES.md](BENCH_VARIABLES.md) 참조.
> 규약: 시각은 UTC 저장(표시만 KST) · 표본 없으면 빈 값 · 개인 식별 변수는 설계상 존재하지 않음

---

## 1. 핵심 지표 — 리포트·안내판·건의서에 나가는 숫자

| 지표 | 정의 | 단위 | 원천 변수 | 공개 조건 |
|---|---|---|---|---|
| **K1** | 등교 시간대 4륜 차량 중 30 km/h 초과 비율 | % | `counts_5min` (cls=veh4, speed_p85) | 상시 |
| **K2** | 정차 구역 밖 20초 이상 정차 건수 | 건/등교일 | `events` (kind=dwell, zone=no_stop) | 상시 |
| **K3** | 횡단보도에 보행자가 있는 동안 차량이 2 m 이내 접근 | 건/등교일 (프록시) | `events` (kind=conflict) | 상시 |
| **C1** | K2 이벤트의 정차 사유 분포 (승하차/대기/배송/기타) | % 분포 | `inferences` (HYBRID tag) | **GATE 2 통과 후에만** |
| **C2** | 교문 통과(교내 진입·진출) 차량 수 | 대/등교일 | `counts_5min` (교문 가상선) | 상시 |
| **안전 지수** | 100 − Σ w·clip((K − K_base)/K_base), w=(0.4, 0.3, 0.3) | 0~100 | K1~K3 + baseline | 원값 K1~K3 없이 단독 표기 금지 |

## 2. `counts_5min` — 통행량 원천 (5분 버킷)

| 변수 | 뜻 | 값 |
|---|---|---|
| `bucket_utc` | 5분 버킷 시각 (경계 정렬) | UTC ISO8601 |
| `cls` | 통행 주체 분류 | `veh4`(4륜) / `two_wheel`(이륜) / `person`(보행) |
| `dir` | 가상선 통과 방향 | `in` / `out` |
| `n` | 그 5분간 통과 수 — **표본 부족(<5프레임)이면 빈 값** | 대·명 |
| `speed_p85` | 속도 상위 85퍼센타일 — 교통공학 표준 "실질 주행 속도" | km/h (차량류만) |
| `speed_med` | 속도 중앙값 | km/h |
| `calib_ver` | 어떤 캘리브레이션으로 잰 값인가 | calib 표 참조 |

## 3. `ped_5min` — 횡단 보행 (5분 버킷)

| 변수 | 뜻 |
|---|---|
| `cross_n` | 횡단보도 건넌 수 |
| `wait_med_s` | 횡단 대기 시간 중앙값 (초) |

## 4. `events` — 위험 이벤트 원본 (건별)

| 변수 | 뜻 | 값 |
|---|---|---|
| `event_id` | 사건 고유번호 (라벨·판정과 조인 키) | UUID |
| `ts` | 발생 시각 | UTC |
| `kind` | 이벤트 종류 | `dwell`(정차) / `conflict`(횡단 중 근접) / `speeding`(과속) |
| `zone` | 위치 | `no_stop`(금지 구역) / `drop`(승하차 구역) / `crosswalk` / `lane` |
| `duration_s` | 정차 지속 시간 | 초 (dwell) |
| `speed_kmh` | 이벤트 속도 | km/h (speeding·conflict) |
| `dist_m` | 보행자와 최소 거리 | m (conflict, 2 m 기준) |
| `track_cls` | 이벤트 주체 | veh4 / two_wheel |
| `risk_level` | **표시용 최종 판정** (HYBRID 결과 캐시) | SAFE / WARNING / DANGER |

## 5. `analysis` — 배치 인사이트 결과 (대시보드·리포트 원천)

`kind`별로 1일 1행, `payload`는 숫자·enum만 담긴 JSON.

| kind | 내용 | 쓰이는 화면 |
|---|---|---|
| `k1` `k2` `k3` | 그날의 지표 확정값 | 오늘 카드 · 안내판 |
| `safety` | 안전 지수 | 오늘 게이지 |
| `m1` | 요일 기준 프로파일 + 이상 마커 | 프로파일 |
| `m2` | 주간 p85·초과율 추세 (개입 표시 포함) | 속도 |
| `m3` | 정차 핫스팟 군집 (좌표·건수) | 정차 히트맵 |
| `m4` | 위험 시간대 (K3 집중 15분) | 주간 리포트 |

## 6. `qc_5min` — 그 숫자를 믿어도 되는가 (신뢰도 꼬리표)

| 변수 | 뜻 | 해석 |
|---|---|---|
| `qc` | 품질 비트 | **0 = 신뢰** · 0 아니면 그 버킷은 리포트에서 제외/주석 |
| `fps_med` / `fps_p05` | 그 5분의 처리 속도 | p05 < 15면 놓친 통행 가능성 |
| `vlm_dropped` | VLM 큐에서 버려진 이벤트 수 | C1 결측의 원인 표시 |
| `throttle` | 온도 스로틀 발생 | 여름철 데이터 주의 플래그 |

## 7. `outbox` — 사람에게 나가는 문안의 상태

| 변수 | 뜻 |
|---|---|
| `kind` | weekly(주간 리포트) / norm(규범 메시지) / monthly(건의 PDF) |
| `body` | 문안 본문 (숫자마다 근거 병기 규칙) |
| `status` | `draft`(초안, 발송 불가) → `approved`(교사 승인) → `sent` / `rejected` |
| `approved_by` / `sent` | 승인자 · 발송 시각 (승인 로그) |

## 8. 맥락 변수 — 전후 비교의 통제 변수

| 표 | 변수 | 용도 |
|---|---|---|
| `school_cal` | `school_day` | 등교일만 비교 대상 (방학·휴일 제외) |
| `ext_wx` | `rain_mm`, `t_min/max` | 우천일 구분 — 비 오는 날 통행 패턴은 별도 취급 |
| `validation` | `err_pct` | 수동 대조 오차 — 모든 공개 숫자에 "±n%"로 병기 |
| `calib` | `ver`, `reproj_err_m` | 측정 기하의 버전·정밀도 (재투영 오차 < 0.3 m) |

## 자주 쓰는 인사이트 레시피

| 알고 싶은 것 | 쓰는 표 · 변수 |
|---|---|
| 오늘이 평소보다 위험했나 | `analysis(m1)` 기준 프로파일 vs 오늘 `counts_5min` |
| 개입(안내판)이 효과 있었나 | `analysis(k1·k2·k3)`를 개입 전/후 같은 요일끼리 짝지어 비교 (`school_cal`로 등교일 필터) |
| 어디에 드롭존을 늘려야 하나 | `events(dwell)` 좌표 군집(`analysis m3`) + C1 승하차 비율 |
| 몇 시에 안전요원이 필요한가 | `events(conflict)`의 15분 히스토그램 (`analysis m4`) |
| 이 숫자 믿어도 되나 | 해당 기간 `qc_5min.qc=0` 비율 + `validation.err_pct` |
